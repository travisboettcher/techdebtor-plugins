The final message stops before any implementation and asks the human what "better" should mean: it asks for, or proposes for confirmation, concrete testable acceptance criteria (observable behaviour that a test could check). It does not say it has changed, written or committed any code or tests, and it does not present a finished plan as already being carried out. A message that only lists the repository contents, or that reports work done, fails.
