# Writing a `hook`-rung rule

A hook is the right rung only when the mistake can be checked mechanically from the tool call alone (path, command, content), with no judgement. If it needs judgement, it is a `check` instead (`verify-skill.md`), or, before an instruction exists, a clearer instruction.

## Shape

Project scope: config in `<repo>/.claude/settings.json`, script in `<repo>/.claude/hooks/<rule-id>.py`. User scope: `~/.claude/settings.json` and `~/.claude/hooks/<rule-id>.py`. Merge into existing `hooks` arrays; never replace other hooks.

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|MultiEdit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "python3 \"$CLAUDE_PROJECT_DIR/.claude/hooks/<rule-id>.py\"",
            "timeout": 10
          }
        ]
      }
    ]
  }
}
```

The script reads the hook input JSON on stdin (`tool_name`, `tool_input`, `cwd`, ...). Exit `2` with a message on stderr blocks the call and feeds the message back to the agent; exit `0` allows it.

```python
#!/usr/bin/env python3
"""<rule-id>: <one-line summary>. Added by /agent-loop:retro; see .claude/rules-ledger.yml."""
import json
import sys

try:
    data = json.load(sys.stdin)
    path = data.get("tool_input", {}).get("file_path", "")
    with open(path, encoding="utf-8", errors="replace") as f:
        first = f.readline()
except Exception:
    sys.exit(0)  # never block on the hook's own failure

if first.startswith("# Generated by"):
    print(f"{path} is generated. Edit its source and regenerate instead.", file=sys.stderr)
    sys.exit(2)
sys.exit(0)
```

## Requirements

- Standard library only, no network, well under a second.
- Fail open on its own errors (exit 0); fail closed only on the exact mistake.
- The stderr message says what to do instead, not only what is wrong.
- Narrow `matcher` to the tools involved.
- Test it before committing: pipe a sample input that should be blocked and one that should pass, and check the exit codes. Include those two cases in the commit message.
